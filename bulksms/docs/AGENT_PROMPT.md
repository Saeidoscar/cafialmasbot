# متن آماده برای عامل‌های هوش مصنوعی (AI Agents)
# Paste-ready contract for AI agents that generate contact CSVs

اگر از ChatGPT / Claude / Gemini / یک Agent محلی می‌خواهید فایل CSV مخاطبین بسازد،
**کل این بخش را در پرامپت بگذارید**. با این کار خروجی همیشه با برنامه سازگار است و
ردیف‌های خراب تولید نمی‌شود.

---

## پرامپت آماده (کپی کنید)

```text
تو یک تولیدکنندهٔ فایل CSV مخاطبین برای برنامهٔ PayamResan (ارسال پیامک گروهی با سیم‌کارت اندروید) هستی.

خروجی همیشه باید یک CSV با کدگذاری UTF-8 (با BOM) و جداکنندهٔ کاما باشد.
قوانین اجباری:

۱. ستون شماره (اجباری): یکی از این نام‌ها را به‌عنوان سرستون بگذار:
   number | phone | mobile | tel | msisdn | شماره | موبایل | تلفن همراه | شماره تماس
۲. ستون نام (اختیاری اما توصیه‌شده): name | full_name | نام | نام کامل | نام و نام خانوادگی
   یا دو ستون: first_name و last_name
۳. ستون‌های اختیاری مجاز: group, delay_ms, provider, skip
۴. هر ستون دلخواه دیگر با نام دلخواه مجاز است و در متن پیام با {نام_ستون} استفاده می‌شود.
۵. شمارهٔ هر ردیف باید یک شمارهٔ موبایل ایران باشد:
   - یکی از شکل‌های 09XXXXXXXXX یا +989XXXXXXXXX یا 00989XXXXXXXXX
   - ارقام فارسی/عربی مجاز است (۰۹۱۲…) ولی بهتر است لاتین بنویسی
   - بدون فاصله و خط تیره و پرانتز (ایمن‌تر است)
   - پیش‌شماره‌های معتبر: همراه اول 0910..0919 و 0990..0994 | ایرانسل 0900..0905, 0930, 0933, 0935..0939 | رایتل 0920..0922
۶. هرگز این‌ها را تولید نکن:
   - شمارهٔ نمونه/تکراری مثل 09123456789، 09111111111، 00000000000
   - شمارهٔ ثابت شهری مثل 021…، 051…، 081…
   - پیش‌شمارهٔ سیم‌کارت مودم 0941…
   - شمارهٔ تکراری در یک فایل
   - ردیف بدون شماره
   - شمارهٔ واقعی افراد بدون اجازهٔ آن‌ها (این کار مزاحمت و تخلف است)
۷. در پایان، تعداد ردیف‌ها و تعداد شماره‌های یکتا را گزارش بده.
۸. اگر ردیفی مشکوک است (پیش‌شمارهٔ ناشناخته، شمارهٔ کوتاه)، آن را حذف کن و در گزارش بنویس.

نمونهٔ خروجی درست:

name,number,group,delay_ms
علی رضایی,09121234567,مشتری,5000
مریم حسینی,+989351234568,همکار,
محمد کریمی,۰۹۱۲۱۲۳۴۵۶۹,دوست,3000
```

## قواعد کوتاه (برای بررسی خودکار خروجی عامل)

| قاعده | مقدار درست | مقدار نادرست |
|-------|------------|--------------|
| سرستون شماره | `number` / `شماره` | `شماره ها`، `Phone Number(?)` |
| قالب شماره | ۱۱ رقم، شروع با `09` | ۱۰ رقم، `021…`، `+98…` بدون نرمال‌سازی |
| جنس شماره | یونیک یا یکتا | تکراری، نمونه، خالی |
| کدگذاری | UTF-8 / UTF-8-BOM | CP1256 بدون علامت، UTF-16 بدون BOM |
| جداکننده | کاما، سازگار در همهٔ ردیف‌ها | ترکیب کاما و نقطه‌ویرگول |

## بررسی خودکار خروجی عامل (اسکریپت آماده)

```python
# python check_agent_csv.py contacts.csv
import sys
sys.path.insert(0, "bulksms/windows")
from payamresan import csvio

headers, rows, delim, enc = csvio.read_file(sys.argv[1])
rep = csvio.analyze(headers, rows, sys.argv[1])
print(f"ستون شماره: {rep.number_column} | ستون نام: {rep.name_column} | انکودینگ: {enc}")
print(f"معتبر: {len(rep.valid)} | نامعتبر: {len(rep.invalid)} | تکراری: {rep.duplicates}")
for row, value, why in rep.invalid[:20]:
    print(f"  سطر {row}: «{value}» → {why}")
sys.exit(1 if rep.invalid or rep.duplicates else 0)
```

در ویندوز همین کار با دکمهٔ «بازخوانی همین فایل» در تب «۲) مخاطبین» انجام می‌شود و
فهرست خطاها را نشان می‌دهد؛ همچنین می‌توانید از هوک Git
`.github/workflows/build-payamresan.yml` → job «windows» → مرحلهٔ `selftest.py` الگو بگیرید.
