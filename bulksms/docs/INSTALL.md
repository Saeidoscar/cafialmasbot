# راهنمای نصب و رفع اشکال
# Install & troubleshooting (Android + Windows)

## الف) گرفتن فایل‌های ساخته‌شده

فایل‌ها به‌صورت خودکار توسط GitHub Actions ساخته می‌شوند:

1. در گیت‌هاب به تب **Actions** مخزن بروید.
2. آخرین اجرای **Build PayamResan (APK + EXE)** را باز کنید.
3. در پایینِ صفحهٔ اجرا، بخش **Artifacts**:
   - `payamresan-android-apk` → فایل نصبی اندروید (`app-release.apk`, `app-debug.apk`) + `SHA256SUMS-apk.txt`
   - `payamresan-windows-exe` → برنامهٔ ویندوز (`PayamResan-Setup.exe`) + `run.bat` + `README.md`
   - `payamresan-signing-key` (فقط بار اول) → کلید امضا؛ برای اینکه به‌روزرسانی‌های بعدی روی نسخهٔ نصب‌شده نصب شود، آن را در Secrets ذخیره کنید (پایین‌تر توضیح داده شده)
   - `payamresan-gui-preview` → تصاویر تب‌های برنامهٔ ویندوز (پیش‌نمایش)
4. اگر می‌خواهید همین حالا بسازید: Actions → Build PayamResan → **Run workflow**.

> اگر مخزن عمومی باشد، ساخت روی runnerهای گیت‌هاب رایگان است.

## ب) نصب روی اندروید (Poco M5s — HyperOS/MIUI)

1. فایل `app-release.apk` را در گوشی کپی/دانلود کنید.
2. برای نصب، اجازهٔ «نصب برنامه‌های ناشناس» را به برنامه‌ای که فایل را باز می‌کند بدهید
   (فایل‌منیجر/مرورگر): تنظیمات → برنامه‌ها → مدیریت برنامه‌ها → دسترسی‌های ویژه →
   نصب برنامه‌های ناشناس.
3. اپ **پیام‌رسان گروهی** را باز کنید و این دسترسی‌ها را بدهید:
   - **ارسال پیامک (SMS)** — اجباری (بدون آن هیچ ارسالی ممکن نیست)
   - **تلفن / Phone** — برای تشخیص سیم‌کارت‌ها
   - **اعلان‌ها (Notifications)** — برای سرویس پیش‌زمینه
   - برای خواندن صندوق ورودی و تشخیص «لغو»: **خواندن پیامک**
4. چند تنظیم مهم روی Poco M5s برای اینکه ارسال نیمه‌کاره قطع نشود:
   - تنظیمات → باتری و کارایی → **صرفه‌جویی باتری برنامه‌ها** → پیام‌رسان گروهی → **محدودیتی نباشد**
   - تنظیمات → برنامه‌ها → پیام‌رسان گروهی → **اجرای خودکار (Autostart)** را روشن کنید
   - در فهرست برنامه‌های اخیر، اپ را **قفل (Lock)** کنید تا با پاک کردن برنامه‌های اخیر بسته نشود
   - **قید ۶ ساعتهٔ سرویس پیش‌زمینه:** در اندروید ۱۴ سرویس‌های `dataSync` حداکثر ~۶ ساعت
     پیوسته فعال می‌مانند. اگر می‌خواهید بیشتر بفرستید، «خودکار فردا ادامه بده» را فعال
     کنید و صف را در چند نوبت بفرستید.
5. **دو سیم‌کارت (همراه اول + ایرانسل):** در اپ، تب «۳» فهرست «سیم‌کارت ارسال» را باز
   کنید و سیم‌کارت همراه اول خود را انتخاب کنید. در تنظیمات اندروید هم بهتر است
   «سیم‌کارت پیش‌فرض برای پیامک» را همان سیم‌کارت تعیین کنید.
6. **فایل CSV** را در گوشی بسازید یا کپی کنید؛ در تب «۱» دکمهٔ «انتخاب فایل CSV» را بزنید.
   فایل‌های داخل `Downloads`، حافظهٔ داخلی و Google Drive (در صورت وصل بودن) قابل انتخاب‌اند.
7. متن پیام را در تب «۲» بنویسید و در تب «۴» **شروع ارسال** را بزنید.

## ج) نصب روی ویندوز

1. فایل `PayamResan-Setup.exe` را از Artifacts بگیرید (زیپ را باز کنید).
2. روی فایل راست‌کلیک → Run (اگر SmartScreen هشدار داد: More info → Run anyway).
3. بار اول، Windows Firewall اجازهٔ شبکهٔ محلی را بپرسد → **Private networks** را تیک بزنید.
4. در تب «۱» اپ اندروید، «روشن کردن پل» را بزنید؛ آدرس مثل `http://192.168.1.45:8765` و یک
   **توکن** نشان داده می‌شود. همان‌ها را در برنامهٔ ویندوز وارد کنید و «تست اتصال» را بزنید.
   (یا دکمهٔ «جست‌وجو در شبکهٔ وای‌فای» را بزنید تا آدرس گوشی خودکار پیدا شود.)
5. فایل CSV را باز کنید → متن پیام را بنویسید → «شروع ارسال».

> اگر Python روی ویندوز دارید، می‌توانید بدون EXE هم اجرا کنید:
> `pip install -r requirements.txt` و بعد `run.bat`.

## د) اتصال به عامل‌های هوش مصنوعی روی کامپیوتر

هیچ محدودیتی نیست: هر Agent یا اسکریپتی که فایل CSV بسازد، می‌تواند از قوانین
`schema/contacts.rules.json` استفاده کند و سپس یا:

- فایل را به برنامهٔ ویندوز بدهد (ساده‌ترین راه)، یا
- مستقیم با پل HTTP گوشی کار کند (`docs/BRIDGE_API.md`).

نمونهٔ بررسی خودکار فایل تولیدشده توسط Agent: `docs/AGENT_PROMPT.md` (بخش «بررسی خودکار»).

## ه) رفع اشکال

| نشانه | علت و راه‌حل |
|-------|---------------|
| در ویندوز «اتصال به گوشی برقرار نشد» | اپ گوشی باز و «پل» روشن باشد؛ هر دو روی یک وای‌فای باشند؛ VPN/کلاینت‌های امنیتی خاموش؛ فایروال ویندوز اجازه بدهد؛ IP و پورت را چک کنید |
| «توکن نامعتبر است» | توکن اپ گوشی را دوباره کپی کنید (بدون فاصله). توکن در فایل `bridge-token.txt` هم ذخیره است |
| ارسال نمی‌شود و «خطای عمومی مخابراتی» می‌گیریم | سیم‌کارت محدود شده (سقف اپراتور)، اعتبار کم است، یا حالت پرواز روشن است |
| «پوشش شبکه نیست» | آنتن گوشی ضعیف است؛ گوشی را جابه‌جا کنید |
| تمام پیام‌ها در گوشی «خطا» شدند | «سیم‌کارت ارسال» در تب ۳ اشتباه انتخاب شده یا در اندروید سیم‌کارت پیش‌فرض پیامک تغییر کرده |
| متن فارسی در فایل CSV به‌هم‌ریخته است | فایل را با **CSV UTF-8 (کاما محدود)** ذخیره کنید؛ یا از حالت «windows-1256» استفاده کنید که پشتیبانی می‌شود |
| شماره‌ها با صفر ابتدایی خراب شده‌اند | در اکسل ستون شماره را Text کنید یا همهٔ شماره‌ها را با `+98` بنویسید |
| ارسال بعد از قفل شدن گوشی قطع می‌شود | تنظیمات باتری و Autostart را طبق بند ب) ۴ انجام دهید |
| نصب نسخهٔ جدید APK روی نسخهٔ قبلی کار نمی‌کند | کلید امضای بیلدها یکی نیست: یا نسخهٔ قبلی را حذف کنید، یا `payamresan-signing-key` را در Secrets ذخیره کنید (پایین) |
| اپ گوشی هنگام ارسال از برنامهٔ اخیر حذف و بسته می‌شود | اپ را در فهرست اخیر قفل کنید؛ همچنین «سرویس پیش‌زمینه» باید در نوار اعلان دیده شود |

### ثابت کردن کلید امضا (اختیاری اما توصیه‌شده)

اجرای اول یک آرتیفکت به نام `payamresan-signing-key` می‌سازد (شامل `payamresan.p12` و
`README.txt` با رمز). برای اینکه همهٔ APKهای بعدی با همین کلید امضا شوند:

1. فایل `payamresan.p12` را دانلود کنید.
2. در گیت‌هاب: Settings → Secrets and variables → Actions → New repository secret
   - `PAYAMRESAN_KEYSTORE_B64` = خروجی `base64 -w0 payamresan.p12`
   - `PAYAMRESAN_KEYSTORE_PASSWORD` = رمزی که در `README.txt` آمده
3. از این پس همهٔ بیلدها با همین کلید امضا می‌شوند و به‌روزرسانی بدون حذف نسخهٔ قبلی نصب می‌شود.

بدون این کار، هر بیلد کلید تازه می‌گیرد (یا از کش استفاده می‌کند) و ممکن است لازم باشد
نسخهٔ قبلی را حذف کنید.

## و) ساخت دستی از سورس

```bash
# اندروید (نیاز به JDK 17 + Android SDK)
cd bulksms/android
gradle assembleRelease        # خروجی در app/build/outputs/apk/release/

# ویندوز
cd bulksms/windows
pip install -r requirements.txt pyinstaller
python tools/selftest.py            # تست قوانین و CSV
python tools/gui_smoke.py preview   # تست رابط گرافیکی + تصاویر
pyinstaller --noconfirm --onefile --windowed --name PayamResan-Setup \
  --add-data "payamresan/icon.png;payamresan" PayamResan.py
```
